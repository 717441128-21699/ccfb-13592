# 自动演奏钢琴 · 纸卷打孔排版工具

把 MIDI 文件按指定纸卷规格排成一比一的打孔图,输出给数控冲床。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 构建到 dist/
node test/selftest.ts   # 排版引擎自测(无需浏览器)
```

打开页面后:导入 MIDI(或点"载入示例曲")→ 选纸卷规格 → 自动排版 → 缩放检查 → 导出。

## 功能对应

| 需求 | 实现 |
|---|---|
| 88音/65音、每英寸孔位、纸速 | 左侧面板全部可调,预设见 `src/layout.ts` 的 `PRESET_88` / `PRESET_65` |
| 音符 → 孔位孔长 | 时间 × 纸速 = 纵向位置;音高 → 横向轨道;附加油琴步距吸附 |
| 踏板/力度另起轨道 | 低音力度、延音踏板、高音力度三条控制轨放在两侧纸边(与真卷表达孔位置一致) |
| 纸桥 ≥ 2mm | 同轨道相邻孔间距不足时自动缩短前一个孔;缩短后不足最小孔长的音舍弃并告警 |
| 力度分两半区 | 扫描线求各半区每时段激活音符力度均值,时长加权 k-means 量化成 N 档 —— "全区一个力度"约束下总误差最小的分配 |
| 5 秒内出图 | 2 万音符实测约 0.12s;Canvas 只画可视区域内的孔 |
| 一比一出图 | "1:1 实际大小"按钮,按校准后的屏幕 DPI 显示真实尺寸;导出 DXF 单位为毫米 |

## 纸速惯例

纸卷速度标号 T ⇒ T/10 英尺/分钟(如标号 80 = 40.6 mm/s)。面板直接填标号。

## 导出格式

- **CSV**:每个孔一行(轨道、类型、x、y、孔长、孔宽),适合自己写冲床后处理
- **JSON**:完整排版结果(规格 + 轨道 + 全部孔位)
- **DXF**(R12):每个孔一个 SOLID 实体,单位毫米,按 NOTES / PEDAL / DYNAMICS 分层,多数 CAM/冲床软件可直接读取

## 规格默认值(按常见卷纸,可在面板改)

| | 88音 | 65音 |
|---|---|---|
| 音域 (MIDI) | 21–108 | 33–97 |
| 每英寸孔位 | 9 | 6 |
| 纸宽 | 287 mm | 287 mm |
| 速度标号 | 80 | 70 |

> 老琴的实际规格(孔距、纸宽、边距、冲孔直径)建议用卡尺量一卷原纸后填进面板,数值会自动保存到本次会话。

## 已知取舍

- 密集重复音在纸速下若物理上排不下(纸桥不足且缩短后低于最小孔长),该音被舍弃并在面板告警 —— 需要降低纸速标号重排。
- 力度档数默认 4 档,对应琴上气压分档;档数可在面板调(1–8)。
- SMPTE 时间格式的 MIDI 暂不支持(绝大多数 MIDI 是 PPQN 格式)。
